## Para mirar de cerca

1. **Structured outputs para Claude en Bedrock:** elimina la capa de validación y reintento en pipelines de extracción. Hay que tenerlo como opción por defecto en los diseños nuevos.
2. **AgentCore Gateway con InvokeModel y fallback:** permite mover la resiliencia entre proveedores al Gateway. Conviene compararlo con un fallback propio en la próxima propuesta de agentes.
3. **Guardrails grounding Standard:** mejora la detección de alucinaciones, pero obliga a usar cross-Region inference. Hay que revisar la residencia de datos antes de recomendarlo.
4. **ECS Gateway:** reduce la plomería de ingress en Fargate. Junto con Lambda Web Functions (W43), cambia la comparación de hosting para APIs de agentes.
